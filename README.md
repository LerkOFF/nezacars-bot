# nezacars-bot

Telegram-бот каталога автомобилей автосалона «Независимость»: `@nezacars_bot`. Меню и ответы повторяют `@chinacars_market_bot`.

Бот не хранит состояние и работает только через deep-link `/start <payload>`. Ссылки в кнопках меню ведут обратно в этот же чат.

| payload | ответ |
| --- | --- |
| пусто, `catalog` | главное меню: 6 категорий, «БРЕНДЫ», 18 марок по две в ряд, «Как заказать» |
| `cat_pickup`, `cat_minivan`, `cat_sedan`, `cat_offroad`, `cat_crossover`, `cat_electric` | список авто категории |
| `brand_<ключ>` (`brand_Toyota`, `brand_Citroen`, `brand_Uaz` ...) | список авто марки; если пусто, «Сейчас автомобилей X нет в каталоге» |
| `howto` | «Как заказать» |
| любое другое | главное меню |

Бот не принимает запросы: все заказы идут по ссылке «Заказать» на форму сайта. Каждый список заканчивается ссылками «Заказать» и «Вернуться в каталог» (`footer_links` в `data/config.json`). Длинные списки режутся на несколько сообщений.

## Запуск

```bash
cp .env.example .env   # BOT_TOKEN
python3 bot.py
python3 -m unittest discover -s tests
```

Только стандартная библиотека Python 3. Токен только в `.env` (в git не попадает).

## Меню-пост в канале

Меню может лежать постом в канале, а не только в боте. Это делает `post_menu.py`:

```bash
python3 post_menu.py @Nezavisimost_Ru --dry-run   # посмотреть, что уйдёт
python3 post_menu.py @Nezavisimost_Ru --pin       # опубликовать и закрепить
```

Бот должен быть админом канала с правом публиковать (и закреплять). Скрипт печатает ссылку на пост.

## Админка

Команда `/admin` в личке с ботом открывает панель на кнопках. Работает только у id из `ADMIN_IDS` в `.env` (через запятую), остальным бот по-прежнему молчит на всё, кроме `/start`.

- список всех авто, по категориям и маркам, скрытые и архив;
- карточка авто: название, цена, ссылка, категория, марка;
- три статуса: 🙈 скрыто (клиенты не видят, можно вернуть), 📦 в архиве (то же, с датой), 🗑 удалено (с подтверждением);
- добавление авто: переслать боту пост из канала (ссылка берётся из пересылки, название и цена угадываются из текста и показываются на проверку) или прислать ссылку на пост и ввести название и цену;
- журнал изменений и кнопка «Отменить последнее».

`data/catalog.json` из git остаётся исходной базой, правки админов лежат отдельно в `state/edits.json` (папка `state/` в `.gitignore`, `git pull` её не трогает, путь меняется переменной `STATE_DIR`). Файл `state/` нужно сохранять при бэкапах сервера. Новые марки и категории, тексты и менеджеров по-прежнему правят через `data/config.json`.

## Данные

- `data/config.json`: тексты, раскладка меню, `footer_links` (ссылки в конце списков), необязательная кнопка под сообщением (`back_button`, `back_url`), менеджеры для текста «Как заказать» (`managers`: `[{"name": "Сергей", "url": "https://t.me/..."}]`, сейчас пусто), префикс цены `price_prefix` («от »).
- `data/catalog.json`: `cars` (`id` → `title`, `price` числом или `null` = «цена по запросу», `url` карточки), `categories` и `brands` (заголовок и упорядоченный список id авто). Файлы перечитываются на лету, перезапуск не нужен.

### Как добавить марку или категорию

1. В `data/catalog.json` добавить запись в `brands` (например `"Peugeot": {"header": "🚖 Peugeot", "cars": []}`) и авто в `cars`, затем id авто в `cars` марки.
2. В `data/config.json` в `menu` добавить кнопку `{"text": "Peugeot", "start": "brand_Peugeot"}`.
3. `python3 -m unittest discover -s tests`: тест проверяет, что у каждой марки и категории есть кнопка и все ссылки на авто существуют.

Марка без авто сама покажет «нет в каталоге».
