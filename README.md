# nezacars-bot

Telegram-бот каталога автомобилей автосалона «Независимость»: `@nezacars_bot`. Меню и ответы повторяют `@chinacars_market_bot`.

Бот не хранит состояние и работает только через deep-link `/start <payload>`. Ссылки в кнопках меню ведут обратно в этот же чат.

| payload | ответ |
| --- | --- |
| пусто, `catalog` | главное меню: 6 категорий, «БРЕНДЫ», 18 марок по две в ряд, «Как заказать» |
| `cat_pickup`, `cat_minivan`, `cat_sedan`, `cat_offroad`, `cat_crossover`, `cat_electric` | список авто категории |
| `brand_<ключ>` (`brand_Toyota`, `brand_Citroen`, `brand_Uaz` ...) | список авто марки; если пусто, «Сейчас автомобилей X нет в каталоге» и ссылка «Отправить запрос» |
| `howto` | «Как заказать» |
| любое другое (`Peugeot`) | «Спасибо за обращение», запрос уходит админам; если у человека нет `@username`, через `followup_delay_sec` (по умолчанию 20 минут) бот сам пришлёт «Не можем написать вам с личного аккаунта менеджера…» с кнопкой «💬 Написать <менеджер>» |

Каждый список заканчивается ссылками «Заказать» и «Вернуться в каталог» (`footer_links` в `data/config.json`). Длинные списки режутся на несколько сообщений.

## Запуск

```bash
cp .env.example .env   # BOT_TOKEN, ADMIN_CHAT_IDS
python3 bot.py
python3 -m unittest discover -s tests
```

Очередь отложенных сообщений лежит в `state/followups.json` (в git не попадает) и переживает перезапуск. Для проверки задержку можно сократить: `FOLLOWUP_DELAY_SEC=15`.

Только стандартная библиотека Python 3. Токен только в `.env` (в git не попадает). Админ должен один раз нажать Start у бота, иначе уведомления о запросах не дойдут.

## Меню-пост в канале

Меню может лежать постом в канале, а не только в боте. Это делает `post_menu.py`:

```bash
python3 post_menu.py @Nezavisimost_Ru --dry-run   # посмотреть, что уйдёт
python3 post_menu.py @Nezavisimost_Ru --pin       # опубликовать и закрепить
```

Бот должен быть админом канала с правом публиковать (и закреплять). Скрипт печатает ссылку на пост.

## Данные

- `data/config.json`: тексты, раскладка меню, `footer_links` (ссылки в конце списков), необязательная кнопка под сообщением (`back_button`, `back_url`), менеджеры (`managers`: `[{"name": "Сергей", "name_instr": "Сергеем", "name_dat": "Сергею", "url": "https://t.me/..."}]`, `name_instr` и `name_dat` для падежей в текстах («с менеджером Сергеем», «Написать Сергею»), сейчас пусто; для отложенного сообщения используется первый), тексты `followup_*`, префикс цены `price_prefix` («от »).
- `data/catalog.json`: `cars` (`id` → `title`, `price` числом или `null` = «цена по запросу», `url` карточки), `categories` и `brands` (заголовок и упорядоченный список id авто). Файлы перечитываются на лету, перезапуск не нужен.

### Как добавить марку или категорию

1. В `data/catalog.json` добавить запись в `brands` (например `"Peugeot": {"header": "🚖 Peugeot", "cars": []}`) и авто в `cars`, затем id авто в `cars` марки.
2. В `data/config.json` в `menu` добавить кнопку `{"text": "Peugeot", "start": "brand_Peugeot"}`.
3. `python3 -m unittest discover -s tests`: тест проверяет, что у каждой марки и категории есть кнопка и все ссылки на авто существуют.

Марка без авто сама покажет «нет в каталоге» и предложит отправить запрос.
